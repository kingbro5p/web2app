১. তথ্য দিন

অ্যাপের নাম, প্যাকেজ আইডি ও আপনার ওয়েবসাইটের লিংক ফর্মে দিন।

২. আসল বিল্ড চলে

এই সাইট একটি GitHub Actions ওয়ার্কফ্লো ট্রিগার করে, যা Cordova দিয়ে সত্যিকারের Android প্রজেক্ট বিল্ড করে।

৩. ডাউনলোড করুন

বিল্ড শেষ হলে APK ফাইল GitHub Release-এ আপলোড হয় — সরাসরি ডাউনলোড লিংক পেয়ে যাবেন।

দ্রষ্টব্য: তৈরি APK একটি unsigned debug বিল্ড — টেস্টিং ও সাইডলোডের জন্য উপযুক্ত। Play Store-এ প্রকাশ করতে চাইলে নিজের রিলিজ কী দিয়ে সাইন করে নিতে হবে।
